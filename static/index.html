    Стена Перегородка Окно

    Стена/перегородка: две точки. Дверь или окно: нажмите рядом со стеной. Выбор: дверь перетаскивается на ближайшую стену; окно переносится на другую стену с Alt. Delete — удаление. Пробел + перетаскивание — сдвиг всего плана.

    Инженерные системы

    0 размещено

    Один план может содержать СКУД, домофонию, СОТ и СКС. Выберите прибор нужной системы и укажите место на плане.

    Кабельные трассы и материалы добавим следующим самостоятельным инструментом.

    Объёмный вид

    Наклон от вида сверху: 0° — сверху, 70° — низкий ракурс.

    Мышь — вращение; Shift + перетаскивание — сдвиг; колесо — масштаб. Двойной щелчок — весь план.

    Высоты условные. Иллюстративная визуализация. Не для монтажа.

    Навигация
